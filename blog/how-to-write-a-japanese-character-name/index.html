How to Write a Japanese Character Name: Order, Surname vs Given Name, and Picking Kanji That Fits

Picking a Japanese name for your character is two decisions, not one. The first is the sound — what the name sounds like when someone says it out loud. The second is the kanji — what the name means when it is written down. Get the order of those two wrong and the name will feel off in a way that is hard to name. Here is the mechanics, and then the five steps that produce a name that works.

This is the writing guide that sits underneath the selection guide. If you already know which name you want and need to know how to write it correctly, start at step one. If you are still choosing, read the six-step selection method first, then come back here.

1. The order: family name first

A Japanese name is written family name, then given name, with a space between them:

佐藤 陽翔 — Satō Haruto. The family name is 佐藤, the given name is 陽翔.

This is the reverse of English and of most Western writing, and it is the single most common mistake when a name is written by someone who does not read Japanese. It is also not a rule you can ignore: the order is how the name goes on a form, an envelope, a nameplate and a business card in Japan, and how a character introduces themselves.

The reverse order — given name first — is what you get when a Japanese name is romanised for an English-language context. "Haruto Satō" and "Satō Haruto" are the same person, written for different readers. A character with a Japanese name in an English story is usually romanised that way; a character in a Japanese setting is not.

2. Surname and given name do different jobs

The family name is shared: siblings, cousins and a whole family line carry it. The given name is the individual. That is why a Japanese character's given name is the one that carries the meaning, and it is why the given name is the one to build a character around.

There is one more thing about the family name that matters for writing: a Japanese family name is almost always written with kanji, and the kanji are not decorative. They usually carry a place of origin or a trade — 藤 (fuji, wisteria) is one of the most common elements in Japanese family names, and the compound is often traceable to a place that had wisteria. That is a background detail an author can use, and a detail that is invisible to a reader who does not know it, which is exactly the kind that rewards a second reading.

3. Kanji and reading: the kanji decides

The single most useful thing to know about Japanese names is that the kanji decide the reading, not the other way round. The same reading can be written in many different ways, and the meaning of the name is decided by which kanji you chose.

明日 can be read ashita (tomorrow), asu, or myōnichi (the formal written form of "tomorrow"). All three are real readings of the same two characters. The reading is a property of the kanji combination, and it is checked against dictionaries.

For a character name this means the writing order is:

  1. Decide the sound the name should have.
  2. Find the kanji that carry that sound.
  3. Check that the combination means what you want it to mean.

All of the names in the site's word bank are real names, so the reading is not a guess — it is a reading that somebody's child actually has:

  • haruto (陽翔, はると) sun + soar
  • ren (蓮, れん) lotus
  • itsuki (樹, いつき) tree
  • asahi (朝陽, あさひ) morning sun
  • yuki (勇気, ゆうき) courage (alt reading)
  • naoki (直樹, なおき) honest + tree
  • akira (明, あきら) bright
  • himari (陽葵, ひまり) sun + hollyhock
  • rin (凛, りん) dignified, cold-crisp
  • hina (陽菜, ひな) sun + greens
  • haru (春, はる) spring
  • sora (空, そら) sky
  • hikaru (光, ひかる) light, radiance
  • rei (零, れい) zero, spirit
  • yozora (夜空, よぞら) night sky

Look at what the shared kanji do. 陽 (“sun”) opens 陽翔, 陽葵 and 陽菜: three real given names that share a first character and feel like family without being siblings. 明 (“bright”) and 蒼, 光, 樹 do the same job in other names. If you are writing a family, you can give them the same opening character and let the meanings diverge — it is how the language itself marks a family resemblance.

4. The kanji that are fixed, and the ones that are not

Some kanji cannot be chosen freely, because their reading is conventional in a specific word:

  • Months. 一月 is ichigatsu (January) and also means “one month” in other contexts.
  • Numbers. 一 is read ichi on its own, but 一日 is ichinichi (the first of the month) and 一人 is hitori (one person). The number one has more than one reading and the context decides.
  • Okurigana. When a kanji takes hiragana after it, the kanji stops being a name and becomes a word: 通り alone is tōri (a street), and 通り過ぎる is tōri-sugiru (to pass through). A character's given name with okurigana in it is a different kind of object.

The practical rule for a writer: if you are inventing a name, stay with kanji that behave like name kanji — the ones that can be read several ways and carry a single clean meaning. The fixed ones are for the world around the character, not for the character.

5. The kanji nobody wants to explain

Every Japanese kanji has a literal meaning, and some of them are unfortunate in a personal name. 便所 is a toilet. 糞 is excrement. The reason this comes up in naming guides is not that people do it — it is that a character name is read in a scene far more often than it is looked at, and a family member reading it at a table will notice.

The fix is not a smaller vocabulary. It is to check the kanji you have chosen against a dictionary for the combination, not for the individual character. 陽 on its own means sun and is used in thousands of real names; 陽 in combination with an unlucky second character is a different word entirely. Real-name registries are useful here for a practical reason: every name in the site's word bank belongs to a real person, which means the combination is one somebody has already lived with.

6. Writing the name out

A character's name usually appears in three forms, and each one does a different job:

  • Kanji — the formal version. Nameplates, certificates, official documents, the title card at the end of an episode.
  • Hiragana — the spoken version. How a nickname or an affectionate form is written, and how a name is written when the writer wants the sound rather than the meaning.
  • Romanised — the version an English-language story uses, and the version most Western readers will see. Transliteration is a choice: 佐藤 is Satō, Satou, or Satoh, depending on the system.

And the honorific goes last, in Japanese order, after the given name: 佐藤 陽翔さん is Mr. Satō Haruto. It is not 陽翔さん佐藤. The suffix guide covers what each honorific means and who is allowed to use it.

Method

Five steps to a name that works

  1. Say the sound first. Write it in hiragana and say it out loud ten times. If you stumble, change the sound now, not after you have written the kanji around it.
  2. Pick the kanji for the meaning. One or two characters that say what the character is, not what they look like. A name that means “courage” or “morning sun” carries further than one that means “dragon”.
  3. Check the combination. Look up the two characters together, not one at a time. That is how an unfortunate reading hides.
  4. Check it against real names. The IRL Names tab holds real given names with their kanji, reading and meaning — if your combination is already a real person's name, you know exactly how it is read and what it means, which is a good place to start.
  5. Write it in all three forms and keep them consistent for the rest of the story.

Frequently asked questions

What order is a Japanese name written in?

Family name first, then given name, separated by a space: 佐藤 陽翔. When the name is romanised for an English-language context it is usually reversed, given name first. The Japanese order is the one used on documents, nameplates and forms.

Which comes first, the reading or the kanji?

The reading comes first when you are inventing a name, but the kanji decide it in practice. The same reading has many kanji spellings, and the meaning of the name is decided by the combination you choose, not by the sound.

Can a character have a surname with a different reading than the same surname for another character?

Yes. Surnames have a conventional reading, and a family can be written with a different one — that is a real practice, not a mistake. But it is a story decision: if a character has a surname that reads differently from everyone else with the same surname, say so on the page.

How many kanji should a given name have?

One or two is the norm for a given name. Longer given names exist, but they are harder to read at a glance and easier to get wrong in a caption.

Should I write a character's name in kanji or hiragana?

Both, in different places. Kanji for the formal version, hiragana for nicknames and for the sound when the meaning is not the point. If your story is in English, the romanised form is what most readers will see, so keep that consistent too.

Is it a problem if my invented name is a real person's name?

Real names are not protected as such — but if you borrow a name that belongs to a living person, you have taken their name. Using a real name from a public registry is a reasonable starting point for a character, and the site's word bank is built entirely from real names that exist independently of any anime character.
