かわいい & kawaii names

動物・自然・優しい意象を表す実在の日本語単語から組み合わせる、かわいい響きの和風ハンドル。アニメ文化の柔らかく可愛い側面で、ペット・OC・遊び心のあるハンドルネームにぴったり。

融合（フュージョン）和風名

あなたの言語から単語を入力してください（または空欄のままにするとランダムな単語が選択されます）。日本語の単語と組み合わせて、シャドウキツネやムーンダンスなど、アニメ風のかっこいい和風ハンドルを生成します。フォーマットオプション（キャメルケース、スペース、ハイフン、アンダースコア、小文字、パイプ区切り）で、konekomaru や YukiKitsune のようなハンドルネーム風の名前にできます。

実在の和名辞典

男性・女性・性別中立のキャラクター向けに、実在する日本人の名と姓を提供。文化的に本物で、アニメとの直接的な関連はありません。日本で多い100の姓（家族名）と性別タグ付きの名を含み、すべての名前は日常的に使われている実在の日本人名です。

Mythology names

FAQ

これらの名前はどこから来ていますか？

動物・融合（フュージョン）名は実際の日本語語彙（JMdict、 JLPT語彙リスト）から取得しています。IRL Names は公開されている日本人名・姓のデータから取得。神社・お寺の名称は日本の実在する文化施設です。詳細は ATTRIBUTIONS.md をご覧ください。

融合（フュージョン）タブはどのように動作しますか？

融合タブは、あなたの言語の単語と日本語の単語を組み合わせる方式です。あなたの言語の単語を最初に入力欄に入力し（例：「Shadow」「Dream」「Star」）、次に語彙を選択するか、組み合わせ方のオプションを選んでください。生成ボタンを押すと、あなたの単語と日本語の単語を組み合わせた名前（例：ShadowAozora = Shadow + 青空）が表示されます。各ページは独自の言語を持ちます：英語ページでは英語、オランダ語ページではオランダ語、ドイツ語ページではドイツ語、スペイン語ページではスペイン語、フランス語ページではフランス語、ポルトガル語ページではポルトガル語、ポーランド語ページではポーランド語。日本語側は入力に関わらず同じで、動物・自然・クール・単語そのまま名前の語彙プールから取得します。フォーマットオプション（キャメルケース、スペース、ハイフン、アンダースコア、小文字、パイプ）はすべて同じ動作をします。UIにはヒンディー語やタガログ語の融合オプションはなく、これらのロケールで閲覧しているユーザーには同じ英語の融合体験が表示されます。

自分のオリジナルキャラクター（OC）やハンドルネームに使っても安全ですか？

はい。特定のアニメキャラクター名、ファンWikiの名前、特定のフランチャイズに紐づく名前は出力しません。出力は一般的な日本語語彙、公開されている名前登録、神社・神話・武道の用語、そしてあなたの入力した単語から構成されています。意図的に著作権キャラクターに合致する名前を組み立てた場合のIPリスクはユーザー側にありますが、ジェネレーター自体はそのようなターゲットを狙う設計ではありません。

これらの名前を Discord、TikTok、Instagram のユーザー名として使えますか？

問題ありません。生成された名前の所有権や登録は一切行っておらず、リアルタイムの空き状況確認もしていません。ハンドルネームとして使いたい場合は、名前をコピーして各プラットフォームで直接検索してください。

ヤンデレ／少年漫画／異世界のようなカテゴリーがないのはなぜですか？

設計上の方針です。これらのジャンルは特定の作品・原作者に紐づいており、商標・著作権の侵害を避けるため、既存作品から直接名称を引用することは避けています。一般的な日本語語彙・文化・神話・武道の要素をベースにした、IP的に安全な名称に特化しています。

神話タブには何がありますか？

神話タブは、以下の3つの実際の日本文化ソースから名称を生成します：「Source」ドロップダウンで切り替え可能。

⛩️ 神社・お寺 — 伊勢神宮、伏見稲荷大社、鶴岡八幡宮などの実在する神社・お寺。単独の名としても、姓としても使えます。

👹 神話上の人物 — 朱雀、オロチ、稲荷、玉藻、毘沙門、金太郎などの妖怪・神道神・四象・伝説の英雄。古事記、日本書紀、Wikipedia から取得。

⚔️ 武道用語 — 剣聖、侍、刀、武道、剣豪などの実在する日本の武道用語と戦士の称号。

いずれの名称も日本の歴史・神話・武道伝承に実在する文化参照であり、特定の著作権キャラクターや現代作品から派生したものではありません。

男性・女性キャラクターの名前を生成できますか？

はい。IRL Names タブには性別選択機能（男性／女性／指定なしの3オプション）があります。男性（太郎、健一、翔）、女性（花子、美咲、陽菜）、または性別中立的な名前（葵、樹、陽）を選べます。

日本人名、アニメキャラクター名、ニックネームを取得できますか？

3つとも可能です。実在の日本人名（名・姓・両方）が必要な場合は、IRL Names タブで公開されている名前登録から取得。アニメ風のニックネームには、「かわいい」タブで動物・自然・優しい意象の日本語語彙を使用。日本語とあなたの言語をブレンドしたカスタム OC ハンドルには、「融合」タブ（最も一般的）であなたが入力した単語と日本語の単語を組み合わせます。

サイヤ人風、鬼滅の刃風、英雄学科風、海賊団風の名前ジェネレーターはありますか？

ラベル付きカテゴリーとしては用意していません。サイトはIP的に安全な設計のため、特定の作品や商標から直接名前を引用することは避けています。ただし「融合」タブ + 「神話」タブを組み合わせれば、サイヤ人風の強そうな和風名（例：雷神 + 龍 = 雷龍）や、鬼滅風の大和魂を連想させる和名（例：斬月 + 暁 = 斬暁）を生成できます。

これは「かわいい」名前ジェネレーターですか？

Yes — the かわいい tab is exactly that. It pulls from real Japanese words for animals, nature, plants, weather, and gentle imagery (cat 猫, sakura 桜, yuki 雪, momo 桃, etc.) and pairs them with kawaii-friendly suffixes like -chan and -maru. If you want a kawaii name, click the かわいい tab, pick "かわいい" or "Kawaii" suffix, and hit Generate.

和風姓・一族名を取得できますか？

はい — IRL Names タブは日本で多い100の姓（佐藤、鈴木、田中、渡辺、伊藤など）と性別タグ付きの名を提供します。複合的な一族・部族風の名前には、融合タブで姓と姓または姓と神社名を組み合わせてください（例：影 + 一族 = 影一族）。

異世界風・少年漫画戦士風の名前ジェネレーターはありますか？

ラベル付きカテゴリーとしては用意していません。サイトはIP的に安全な設計のため、特定のアニメ・マンガのジャンル名や商標から直接名前を引用することは避けています。「融合」タブ + 「神話」タブ（武士、剣豪、武道用語）を組み合わせれば、異世界・少年漫画的な響きを持つ和風ハンドルを生成できます。

これはオタク／ウェッブ向け名前ジェネレーターですか？

「オタクが作った、オタクの気持が分かるウェッブ向け名前ジェネレーター」という意味であれば、はい。このサイトはアニメ・漫画・和風文化が好きなユーザーが、自分のオリジナルキャラクターやハンドルネームに使える名前を探すために作りました。
